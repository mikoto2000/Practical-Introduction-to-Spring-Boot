# Spring Boot 実践入門

## 概要

Spring Boot を使った Web アプリケーション開発の基本を、コード例とハンズオンで学ぶ教材です。
普段あまり意識せずに使っている機能について、なぜそう書くのか、どこまで気にすべきかをコード例で整理します。
明日からの実装やレビューが少し楽になることを目指します。

## 対象者と読み方

Java のクラス、メソッド、例外の基本を理解している方を対象とします。
Spring Boot が初めての方は、プロジェクト作成から進めてください。
バリデーション以降は、Controller と Service を使った簡単な API の作成経験を前提にします。

[はじめに](docs/introduction.md) に、学習順序と各教材の前提知識をまとめています。
教材サイトの起動・ビルド方法は [DEVELOPMENT.md](DEVELOPMENT.md) を参照してください。
