# はじめに

## 概要

Spring Boot を使った Web アプリケーション開発の基本を、コード例とハンズオンで学ぶ教材です。
普段あまり意識せずに使っている機能について、なぜそう書くのか、どこまで気にすべきかをコード例で整理します。
明日からの実装やレビューが少し楽になることを目指します。

## 対象者と前提知識

Java のクラス、メソッド、コンストラクタ、例外を理解している方を対象にしています。
HTTP の GET / POST、リクエストとレスポンス、JSON の基本も確認しておくと読み進めやすくなります。
Spring Boot が初めてでも、最初のプロジェクト作成ハンズオンから学べます。

各ハンズオンのサンプルは、教材で指定したパッケージ名と依存関係を使って作成してください。
教材ごとに題材が異なるため、原則として別の Java プロジェクトを使います。
Spring Security 第2回は、第1回で作成したプロジェクトを続けて使います。

## 学習の進め方

1. プロジェクト作成で、API の実装・起動・設定・jar の実行を体験する。
2. バリデーションで、不正な入力を処理の入口で止める方法を学ぶ。
3. テスト入門でテストを実装し、開発者テスト入門でケースの選び方を整理する。
4. バリデーションテストで、制約・HTTP・エラー応答を分けて検証する。
5. ロギングと DB マイグレーションで、実行中の調査とデータベースの変更を学ぶ。
6. Spring Security 第1回・第2回で、認証・認可から DB を使うユーザー管理へ進む。

テストの目的から知りたい方は、開発者テスト入門をテスト入門より先に読んでも構いません。
AOP、独自制約、構造化ログ、並行開発の運用は発展内容です。まず基本の動作確認まで進めてから戻りましょう。
DB マイグレーションでは CREATE TABLE / ALTER TABLE、Security 第2回では SELECT / INSERT の基礎が必要です。

## コマンドと動作確認の読み方

コマンドは、各 Java プロジェクトの `pom.xml` があるディレクトリで実行します。
シェルの例は Bash を前提にしています。Windows PowerShell では、Maven の `./mvnw` を `.\mvnw.cmd` に読み替えてください。
PowerShell では `curl.exe` を使うと、同名の別コマンドとの混同を避けられます。
複数行の Bash コマンドは Git Bash で実行してください。

アプリ起動後は別のターミナルからリクエストを送り、HTTP ステータス・本文・ログを確認します。
停止は Ctrl+C です。設定変更後や再起動の説明がある箇所では、前のプロセスを停止してから起動し直してください。
8080 番ポートを使うアプリを同時に起動すると競合するため、ハンズオンを切り替えるときも停止します。

本文の Spring Boot バージョンは教材作成時の指定です。「最新安定版」という意味ではありません。
Spring Initializr で指定版を選べない場合、同じ 4.0 系の利用可能な安定版を選び、生成された依存関係を確認してください。
Security の配布プロジェクトは、その `pom.xml` を基準に進めます。
